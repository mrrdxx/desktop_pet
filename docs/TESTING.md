# 验证规则

这是验证操作说明，不是测试通过报告。任务所需的实际结果记 STATUS 或其链接的阶段证据文件。

## 基本规则

- 完成任务时执行相关验证，阶段结束时做集成验收；无新增风险不重复扩大测试范围。
- 核心逻辑采用可替换时钟、固定随机种子、桌面快照，在无桌面环境下也能测试。
- 窗口输入、透明区、跨 DPI 和拖动手感必须实机验证；构建成功不能替代。
- 无设备/权限时写出“未验证”和原因，不杜撰通过结果。
- 自动测试选择真实边界：中断、到期、跨天、坏存档、负坐标、空洞、超时；不做只重复实现步骤的测试。
- 使用临时目录测试存档，不修改用户真实数据。测试时钟加速不能影响正式默认配置。

## 阶段 0 人工集合

### M-01 透明与输入（必需）

1. 打开一个文本编辑器，在宠物后面放可点击/可输入内容。
2. 点击宠物窗口矩形内部、角色轮廓之外的完全透明点，下层编辑器应直接收到输入。
3. 点击可见实体并拖动，应抓住宠物；释放后不继续跟随。
   头顶、左右耳朵及眼睛上方同样能按住拖动；分别快速拖和慢慢拖，观察首段位移不丢失。头部小幅来回移动仍应作为抚摸，透明耳侧/头顶空白不接管点击；头部向外拖出窗口后仍需保持到松手。
4. 检查动作变化后的透明区，不能因为换帧出现大块不可点击区域。

### M-02 焦点与捕获（必需）

1. 编辑器处于键入状态时拖动宠物，松开后键入仍进入原编辑器。
2. 快速拖出宠物原窗口边界再释放，不丢抓取点，不永久捕获鼠标。
3. 拖动期间切换应用、暂停或触发捕获丢失，宠物能退出拖动状态。
   当前例外：Alt+Tab 拖动切换未达到此预期，用户在 P0-002 收尾时接受现状，详见 [R2 的 KL-001](reviews/P0-002-review.md)；仍记失败与豁免，不能记测试通过。其他场景不随之豁免。
4. 托盘菜单可以正常使用；结束菜单后不会残留输入捕获。
5. P0-002 先验证临时右键菜单：在鼠标附近弹出；点击窗口外空白处关闭；连续重复 3 次仍正常；Esc 可取消；关闭后再点击/拖动宠物不抢焦点；实际点击 Exit 后检查本次 PID 自然退出。未实现的托盘能力留到对应任务。

### M-03 显示器与坐标（单屏必需，多屏实测可选）

1. 分别在 100%、150% 缩放下启动、拖动和找回；记录每次实际设置。
2. 移到工作区边缘；身体仍可操作，找回能恢复完整可见位置。
3. 有第二屏时测试不同 DPI、左侧/上方负坐标及非矩形排列；跨屏不明显跳抓取点。
4. 在副屏保存后断开副屏并重启，宠物回到现有可见屏幕。
5. 无第二屏时第 3–4 项标记未验证，Core 几何测试仍需覆盖对应数据场景。
6. 新增找回入口后，必须实际选择 Recover 并检查本次进程仍运行、窗口完整位于工作区、重复选择后仍可拖动和退出。宠物消失时先区分进程崩溃与窗口屏外；Core 几何测试无法替代 Win32 互操作的集成验证。

### M-04 生命周期（必需）

1. 重复启动，确认没有两个独立写入存档的实例。
2. 暂停后主动行为停止，退出与找回入口仍可操作。
3. 恢复后无动作积压或位置跃迁；真实休眠/锁屏恢复在相关适配实现后补测。
4. 从托盘退出，在进程列表确认进程结束；再启动位置恢复。

### M-05 存档恢复（必需）

1. 使用隔离测试目录，保存后重启，设置和位置保留。
2. 用截断 JSON 模拟损坏，确认保留坏文件、优先有效备份、无备份时默认启动。
3. 写入未知更高 schemaVersion，程序不能无提示地用旧格式覆盖原文件。
4. 正常退出前最后一次位置变更也能保存；频繁拖动不会逐帧写盘。
5. 额外边界：高版本 JSON 将已知字段改为对象/其他类型时，仍保持原文件只读，不能按 v1 解析失败而降级；防抖已完成后再次找回再退出，仍保存最后位置；重启时暂停行为与屏外位置恢复必须验证实际启动链。

可重复的隔离生命周期入口见 [tests/Integration](../tests/Integration/README.md)。它复制当前源码并仅注入测试目录/锁名/观察入口，调用真实菜单事件；与 Shell 图标实际点击的覆盖边界须分开记录。标准单元测试仍使用 dotnet test，不能把其他执行器的结果伪称为正式测试宿主通过。

### M-06 双宠共存（P3-001，计划，尚未执行）

1. 从单宠开始添加第二只，两只可辨认、初始位置合法且不完全重叠，再次添加不超过两只。
2. 分别拖动身体/头部、轻放/甩出A，再操作B；观察未操作一只的位置/速度/个体状态不被串改。沿用M-01/M-02透明命中与焦点要求。
3. 全局暂停使两只冻结、恢复无积压；找回使两只完整可见且不完全重叠；全局退出后无实例残留。对着一只的原右键行为不得误指向另一只。
4. 移除第二只，其窗口消失；第一只仍可操作，重启不复活被删第二只；再次添加得到新稳定ID。
5. 隔离存档：原v3单宠→生产升级→添加第二只/分别移动→保存/退出→生产加载→新对象恢复，核对ID/数量/角色/各自状态和工作区；不手写测试映射代替生产链，不写真实用户存档。
6. 拒绝无效/重复ID及超过上限的恢复数据，具体回退契约先写架构；未知高版本只读、损坏/备份回退与既有委屈/全局稀有计划保护保持。
7. 本任务不验收追逐/寻找或关系数值；未有双窗实际运行不能仅凭集合模型测试标done。显示器/DPI覆盖据实际环境记录，旧单宠结论不直接扩展成双宠已通过。

### M-07 异常诊断（PREP-001，已执行，待监理复核）

1. 建立隔离App子进程/日志目录/存档目录/锁名，核对不访问用户真实存档；经实际早期生产注册入口触发UI、工作线程未处理异常和Task通知，分别记录结果，禁止在用户当前桌宠注入故障。
   - 隔离探针：`tests/DesktopPet.DiagnosticProbe/`（独立可执行项目），测试驱动：`DiagnosticIsolationTests`（4项场景）。
2. 检查日志时间/版本/来源/类型/堆栈、真实进程终止或继续语义。Task通知可在隔离测试安排GC/等待，但不写成确定即时事件；直接调用handler只能证明组件处理，不能证明接线。
   - UI异常（DispatcherUnhandledException）和Worker异常（AppDomain.UnhandledException）通过真实子进程事件验证日志内容和来源。Task通知因GC依赖标注Inconclusive（架构§10已知限制）。
3. 日志目录不可写、记录器失败/重复调用，不得抛第二异常、递归或挂死。正常保存恢复仍有效，未知异常不得强行保存坏状态；使用可识别隔离数据核对。
   - 组件测试 `DiagnosticLoggerTests` 16项验证：不可写目录不抛、Dispose后不抛、重复失败不递归/死锁、并发写入安全、文件滚动/严格保留上限（每文件≤cap、总文件≤maxRetainedFiles）、长异常截断、跨日文件全局清理、单条>cap截断、边界=cap滚动、精确字节有界、锁竞争有界Record/Dispose。
4. 超长记录、文件滚动/保留上限和并发记录按架构初值验证，不上传异常文本；终止边界无法执行的记录明确列限制，不承诺全部崩溃可兜底。
5. 故意异常的非零退出可为预期结果，不因测试宿主退出就将产品改成吞异常。相关原功能回归与异常隔离验证分开报告。
   - 全量回归 Core 351/351 + App 272通过+1跳过 = 623+1，0 回归（R1整改后）。

### M-08 当前Release性能（PREP-003，计划，尚未执行）

1. 固定Release构建与版本摘要，记录Windows/.NET/CPU、显示器/实际窗口DPI、日志开关和其他负载；使用隔离存档、正常退出，不做发布安装。
2. 启动稳定后，空闲至少5分钟、真实拖动/抛掷动态至少2分钟；每种至少两轮同条件测量，复用同一构建。记录操作者/输入方法、动态次数和原始时间戳，不用纯Core模拟冒充窗口负载。
3. CPU累计差和实际经过时间使用同一区间，写明单核百分比及核数归一公式；保留工作集/私有内存/句柄/线程原始数据、首末样本和退出结果。
4. 旧P0 Debug数据仅历史背景，权威值以history/P0-validation.md校正结果为准；不承诺当前一定更低，不把环境差异误作版本性能差异，也不从短时增长断定泄漏。
5. 基线用于未来双宠同环境比较，预算待测后再定；无可靠输入/锁屏/干扰导致中止应单列，不伪记PASS。

## 后续核心自动测试清单

按功能实现时增补，不提前制造全部测试工程：

- 悬停一次触发、移开重置、拖动/抚摸/菜单/暂停中禁用；依D-009，近处/远处快速移鼠不改变表情，不再验证甩动冷却。
- 好奇退出（D-011）：驻留1.2秒进入curious后持续停留，约2秒自动回idle且不重播；仅移到远处/透明点，不点击，离开299ms仍保持、300ms恢复并清除偏移。短暂返回不重播；离开400ms可结束表情但不重新允许触发，满500ms才重新允许、重入仍需完整驻留。暂停中冻结剩余寿命及画面，恢复时不被新驻留重启；其他动作不被覆盖。自动注入与真实鼠标结果分别记证据。
- 眨眼（ART-002）：半闭/闭合PNG与idle逐像素比较，眼部区域外RGBA完全相同，Alpha全图一致，嘴与脚点不变；idle不含content笑脸。固定随机源测3～7秒边界、220ms顺序/非对称时长、低概率双眨的睁眼间隔、中断取消、暂停不补演、长更新间隔弃旧。App验证实际Image.Source为half/closed，CurrentAction保持idle。真实窗口观察多轮时间与Source变化；状态断言不能代替用户主观观感认可。
- 拖动反馈（ART-003）：对真实PNG逐像素验证两处眼/眉区域外RGBA与全图Alpha不变、嘴/脚点不变。Core验证90/180/250ms帧边界、取消/再触发/长间隔、暂停和暂停中开始；App从生产共享手势入口验证松手立即停止捕获与位置、Image.Source过渡、再次头/身体抓取或菜单/其他表情取消、无真实拖动不触发。实机需实际按下拖动→松手不再跟随→看到温和/放松/待机，再在过渡中重新抓起。鼠标被其他程序接管或目标PID不匹配即停止，原始中止日志保留，不将未完成实机链记通过。
- 委屈边界、12小时半衰期、浮点累计、离线衰减、重复结算、日期回拨、次日一次表达；保留暂停退出/回拨连续用例。
- D-013移除回归：旧v2带`affinity`（数字/null/对象）可加载，生产映射保存再重载后无该字段，位置/显示器/暂停/委屈/待表达/日期保留；高版本原文不覆盖。反复头部微移及松开不改变持久化快照，不再验收原+5/1秒计分/2秒冷却或高亲近靠近；头顶双耳/透明区/8DIP转拖动测试仍执行。历史带计分的结果只适用于旧版本。
- 每日随机计划重启不重抽、双宠共享额度、日期回拨不刷奖励。
- 固定步长、卡顿上限、低速停止、角点碰撞、显示器间空洞。
- 社交会话正常结束、任意方被抓起、移除目标、超时、重复取消。
- 空闲会话、夜间跨天、锁屏/睡眠不累计时长。
- 绑定窗口失效、句柄复用识别、目标最小化/关闭后的安全脱离。
