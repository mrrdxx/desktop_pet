- 120×120 实际窗口中可辨闭眼休息姿态。本轮屏幕捕获未覆盖 1.6 秒哈欠开场；原尺寸开场素材沿用 R6 结论。
- 在休息时检测透明边角，工具命中下方窗口并拒发点击，刷新后仍在休息。证明该点命中落到下方，未实际向底层窗口发送点击。
- 真实头部短按后立即从休息图切回待机，日志 28.1 秒已结束，窗口仍为 (100,100)。
- 真实身体拖动结束提醒；12 秒已回 idle，隔离存档的位置从 (100,100) 移至 (150,112)。
- 原生右键 Pause 后，菜单标签变为 Resume，动作保持 idle；选择 Resume 仍为 idle，再开菜单显示 Pause。观察区间提醒计数保持 1。随后从右键 Exit 关闭窗口。
- 真实锁屏、睡眠与提醒中的第二只移除尚未执行。R4 已有系统通知和窗口关闭路径自动证据。
