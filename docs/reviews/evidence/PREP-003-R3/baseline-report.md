## 统计公式

- CPU 累计差：`cpuDelta_ms = last.cpu_ms_total - first.cpu_ms_total`
- 单核 CPU 占比：`cpuPercent = (cpuDelta_ms / (elapsedDelta_s * 1000)) * 100`
- 归一化 CPU 占比：`cpuPercentNormalized = cpuPercent / logicalCores`（logicalCores=24）
- 内存/句柄/线程：首末样本对比，差值 = 末 - 首
